# Articolo 97

Quando perrichiesta del proponente o in base a qualsiasi altra circostanza desumibile dalla natura dell’affare o dagli usi, non sia necessaria una accettazione espressa, il contratto si considera concluso se la proposta non viene rifiutata entro un termine conveniente. Il silenzio vale come accettazione se la proposta si riferisce a relazioni d’affari gia esistenti tra le parti, o se essa é fatta esclusivamente nell’interesse del destinatario.
