# Articolo 623

Il mandante pud, in qualsiasi momento e nonostante ogni patto contrario, revocare o limitare il mandato. Peraltro, se il mandato @ oneroso; il mandante deve indennizzare il mandatario del danno da questi subito a causa della revoca intempestiva o senza giusta causa, Peraltro, se il mandato é conferito nell’interesse del mandatario o di un terzo, il mandante non pud revocarlo o limitarlo senza il consenso della persona nel cui interesse il mandato é stato conferito. :
