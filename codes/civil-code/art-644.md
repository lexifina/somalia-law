# Articolo 644

L’assicurazione è un contratto col quale l’assicuratore, verso pagamento di un premio o altra somma di denaro, si obbliga a fornire all’assicurato o al terzo beneficiario a favore del quale è stipulata l’assicurazione, una somma di denaro, una rendita o altra prestazione pecuniaria, nel caso in cui si verifichi l’evento o il rischio previsto nel contratto.
