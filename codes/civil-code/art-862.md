# Articolo 862

Se il terzo possessore non opta nè per il pagamento dei crediti iscritti nè per la liberazione, nè per il rilascio dell’immobile, il creditore ipotecario non può invocare contro di lui i provvedimenti di espropriazione, in conformità alle disposizioni del Codice di Procedura Civile, se non dopo avergli intimato di pagare il debito esigibile o di rilasciare l’immobile. Tale intimazione è notificata dopo la notifica dell’avviso di espropriazione immobiliare, 0 contemporaneamente a questa.
