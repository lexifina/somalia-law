# Articolo 598

L’appaltatore puod affidare l’esecuzione del lavoro, totalmente o in parte, ad un sub-appaltatore, salvo clausola contraria o se la natura del lavoro non richiede di far appello alle sue attitudini personali,

In tale caso, l’appaltatore rimane respec asabile verso if committente per il fatto del sub-appaltatore.
