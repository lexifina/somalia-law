# Articolo 393

Le lettere firmate hanno la stessa efficacia probatoria delle scritture private. Hala stessa efficacia il telegramma, se l’originale depositato all’ufficio postale é firmato dal mittente. La riproduzione, fino a prova contraria, si presume conforme all’originale. Se Voriginale del telegramma @ distrutto, la riproduzione ha valore puramente indicativo. .
