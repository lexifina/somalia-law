# Articolo 289

Se il debito di un debitore solidale si estingue per prescrizione, la prescrizione non giova agli altri condebitori se non per la parte di tale debitore. Se la prescrizione @ interrotta o sospesa per quanto concerne un debitore solidale, il creditore non pud invocare l’interruzione o la sospensione nei confronti degli altri condebitori.
