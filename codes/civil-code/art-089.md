# Articolo 89

La volonta pud essere espressa verbalmente, per iscritto, 0 con i gesti consuetudinari, oppure con un comportamento che, nelle particolari circostanze, non lasci alcun dubbio sulla vera intenzione delle parti. La dichiarazione di volonta pud essere tacita, quando la legge o le parti non esigono che essa sia espressa.
