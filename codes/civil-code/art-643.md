# Articolo 643

1. Sono escluse dalle disposizioni dell’articolo precedente, le scommesse tra persone che prendono parte a dei giochi sportivi. Peraltro, il giudice può ridurre il premio se questo è eccessivo.

2. Sono altresì escluse le lotterie legalmente autorizzate.
