# Articolo 344

Salvo patto o disposizione contraria, se l’oggetto della obbligazione @ una cosa certa, essa deve essere consegnata nel luogo in cui x si trovava quando l’obbligazione é sorta.

Per le altre obbligazioni, l’adempimento @ dovuto nel luogo in cui si trova il domicilio del debitore al tempo del pagamento, o nel luogo in cui si trova la sede della sua attivita, se l’obbligazione é in relazione a tale attivita.
