# Articolo 217

x La costituzione in mora non @ necessaria nei casi seguenti:

a) Se Vadempimento dell’obbligazione diviene impossibile o inutile per fatto del debitore.

b) Se Voggetto dell’obbligazione @ un indennizzo dovuto a motivo di un fatto illecito.

c) Se l’oggetto dell’obbligazione é la restituzione di una cosa che il debitore sa essere stata rubata, o di una cosa che egli aveva, con conoscenza di causa, indebitamente ricevuto.

d) Se il debitore dichiara per iscritto di non volere adempiere Vobbligazione.
