# Articolo 594

Quando l’appaltatore ha terminato V’opera e Vha messa a disposizione del committente, questi deve, appena possibile, prenderla in ‘consegna secondo la prassi degli affari. Se, malgrado l’intimazione fattagli per via legale, si astiene senza giusta causa dal prenderla in consegna, l’opera si considera consegnata.
