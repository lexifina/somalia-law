# Articolo 635

If giudice pud ordinare il sequestro: Nei casi previsti dall’articolo precedente, in mancanza di accordo tra le parti interessate; Se si tratta di mobili o immobili per i quali l’interessato ha fondato motivo di tenere un pericolo imminente nel caso in cui restassero presso i) oocecssore; In ogni altro caso previsto dalla legge.
