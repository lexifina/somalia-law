# Articolo 904

L’anticresi & opponibile ai terzi anche se il creditore da l’immobile in affitto al costituente. Se l’affitto é stipulato nell’atto costitutivo, deve essere menzionatonell’iscrizione dell’anticresi; ma se Vaffitto é stipulato posteriormente, deve esserne fatta menzione a marginedi tale iscrizione. La menzione non é necessaria se l’affitto é tacitamente rinnovato.
