# Articolo 471

In caso di vendita di una eredita, il trasferimento dei diritti che essa comprende non ha luogo riguardo ai terzi che con l’adempimento delle formalita richieste per il trasferimento di ciascuno di tali diritti. Se la legge prescrive delle formalita per il trasferimento di tali diritti tra le parti, tali formalita devono anch’esse essere adempiute.
